Noxy CRM — conexión de cron y bot

1. En Vercel Production conserva CRON_SECRET. No lo copies al repositorio. Los tres jobs activos en cron-job.org ya lo usan como Authorization: Bearer <CRON_SECRET>.
2. El job existente «Avisa de follow-ups de deals vencidos» ejecuta GET /api/cron/followups cada hora. Su lógica crea tareas a 24 h, 3 y 7 días y mueve leads sin actividad a Perdido a los 14 días. El cierre automático solo aplica a leads creados desde el 14 de noviembre de 2026; configura CRM_AUTOMATION_START_AT en Vercel para cambiar el inicio. No crees un segundo job.
3. El job existente «Resumen periódico por WhatsApp» ejecuta GET /api/cron/digest cada 15 minutos. El resumen diario del CRM quedó activado para las 09:00, zona America/Cancun. El endpoint comprueba la hora y evita duplicados.
4. El job existente «CRM Noxy (Copia)» ejecuta GET /api/cron/payment-alerts cada hora. Se probó con HTTP 200 y respuesta {"alerted":0,"failed":[]}. Avisa al dueño dos días antes; no envía mensajes a clientes. Los jobs duplicados «CRM Digest» y «CRM VIDEOS» quedaron inactivos.
5. Para revisar los jobs: pulsa Run now en cron-job.org. HTTP 200 indica ejecución; HTTP 401 indica secreto incorrecto. Comprueba tareas, digest y alertas en el CRM. El digest solo se envía a la hora configurada.
6. Para el bot HTTP, NOXY_BOT_TOKEN y NOXY_BOT_ORGANIZATION_ID ya están en Vercel Production. El token local está en .env.bot.local (ignorado por Git, permisos 0600); no lo copies al repositorio ni uses CRON_SECRET. Envía Authorization: Bearer <NOXY_BOT_TOKEN>. Rutas: GET /api/bot/daily, GET /api/bot/weekly-videos, POST /api/bot/lead con JSON {"title":"...","notes":"..."}, POST /api/bot/task con JSON {"title":"...","description":"..."}, POST /api/bot/payment-received con JSON {"id":"..."}. Las tres rutas POST devuelven el id creado o actualizado. El bot no envía WhatsApp a clientes; los textos sugeridos requieren aprobación humana.
7. Migración de videos APLICADA el 14 de noviembre de 2026 con Prisma a la base u627288392_noxybd. Verificación: tabla Video presente, 25 columnas, 4 claves foráneas y 0 registros iniciales. prisma/sql/videos.down.sql revierte el esquema, pero elimina los registros de videos creados: exporta esos datos antes de revertir.

URL pública actual: https://www.noxthy.co

8. Integración MCP (preferida para Grok Bot): el conector «noxy-crm» ya apunta a https://www.noxthy.co/mcp. Se autentica con OAuth 2.1 del CRM o MCP_API_KEY. Tools nuevas: get_daily_summary, get_weekly_video_report, create_lead y mark_payment_received; create_task ya existía. Para marcar un pago, la tool devuelve un enlace de aprobación humana y exige approvalToken. Ninguna tool envía WhatsApp a clientes. Tras cada despliegue, vuelve a cargar las tools del conector si el bot no reconoce las nuevas. Las rutas HTTP /api/bot/* siguen disponibles para clientes que no soporten MCP.
